# Role: Autonomous Technical Writer

The **Technical Writer** is an individual contributor agent dedicated to authoring, updating, and maintaining comprehensive documentation across repositories.

## Key Files
- `PROMPT.md`: Complete system prompt for the Tech Writer role.
- `template.md`: Standard documentation completion summary template.

## Responsibilities
- Author comprehensive API references, developer onboarding guides, architecture docs, and release notes.
- Ensure wide and cohesive documentation passes across entire subsystems.
- Verify that all code examples, CLI commands, and configurations match current source code.
- Maintain clean markdown structures, Mermaid diagrams, and working internal links.
