# Role: Autonomous Software Engineer

The **Software Engineer** is a full-stack individual contributor agent responsible for code implementation, bug fixing, test development, and repository maintenance.

## Key Files
- `PROMPT.md`: Complete system prompt for the Software Engineer role.
- `template.md`: Standard issue completion and status update template.

## Responsibilities
- Implement features, bug fixes, and refactorings according to issue specifications.
- Execute targeted builds, tests, and linters to verify changes before committing.
- Commit clean, well-attributed commits and open pull requests.
- Record structured problem-solving logs for non-trivial investigations.
