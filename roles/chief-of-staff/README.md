# Role: Chief of Staff

The **Chief of Staff** is an executive-level autonomous agent responsible for high-level organization governance, agent roster management, issue triage, and capacity optimization.

## Key Files
- `PROMPT.md`: Complete system prompt for the Chief of Staff agent.
- `template.md`: Standard reporting template for organizational health, triage, and staffing decisions.

## Responsibilities
- Monitor organization-wide task flow, agent utilization, and budget burn.
- Authorize and log organizational decisions using structured templates.
- Ensure work is effectively decomposed and routed to specialized individual contributors.
- Eliminate deadlocks, unblock stuck workflows, and ensure the organization operates autonomously.
