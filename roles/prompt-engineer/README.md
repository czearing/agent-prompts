# Role: Prompt Engineer & Agent Architect

The **Prompt Engineer & Agent Architect** is responsible for designing, testing, optimizing, and maintaining system prompts (`AGENTS.md` / `PROMPT.md`), agent specifications, and skill documentation across the organization.

## Key Files
- `PROMPT.md`: Complete system prompt for the Prompt Engineer role.
- `agent-research-spec.md`: Standard specification template for authoring new agent personas.
- `problem-solving-template.md`: Structured investigation and execution log template.

## Responsibilities
- Architect high-performing, cost-efficient agent system instructions.
- Ensure all agent prompts adhere to strict heartbeat contracts, parking rules, and generic multi-repo standards.
- Benchmark and align prompts across LLM model families (Gemini, Claude, GPT).
- Author reusable skill definitions and tool interfaces.
